# 今日老婆插件控制台

在支持原生插件页面的 AstrBot 中重载插件，点击侧栏「今日老婆插件」。控制台由 AstrBot 负责登录鉴权和资源托管，无需额外端口、前端安装或CDN。界面使用紧凑统计卡片、分层标题、浅蓝图表区域、顶部标签和左侧插件Logo，不显示群友头像。

## 页面

- **运行总览**：当前群的今日关系方向数、有效互动与求婚统计、近60天事件趋势、今日老婆关系分类汇总。
- **今日老婆关系图**：读取与群内「关系图」同一份今日老婆记录，使用同一个图谱引擎，按关系自动排布昵称，关系较多的成员字号稍大。展示全部今日关系成员和连线，不再截断为40人/120条；滚轮、触控手势或按钮缩放，拖动画布平移、拖动昵称整理位置，「适应画布」查看全图，「查看大图」展开（Esc收起）。双击昵称或在左侧选择成员可筛选，「看全群的关系」恢复全图。显示抽中、挑中、强娶、求婚成功等方向与文字标签，下方为完整关系表格。分手、重置、换日后随原记录更新。原记录不足以区分来源时标为「结缘」。不需要开启好感度；使用插件原有全局群名单。
- **好感度明细**：昵称搜索、方向切换、当前分项、7/30/60天曲线和可展开的变化账本。
- **好感度关系图**：带方向与分数的文字节点，支持拖动和最低分筛选。两个好感度页面均遵守全局与独立群名单。
- **运行日志**：接入AstrBot logger，只保留来源属于本插件的日志。可按级别、关键词筛选，每3秒刷新。内存最多1000条，单次最多返回500条；从插件启动后开始，重载清空，不读取其他插件日志或修改AstrBot全局日志级别。插件已有debug开关仍决定详细日志是否输出。
- **配置中心**：直接根据`_conf_schema.json`显示开关、数字、选项、名单和小模型配置，与AstrBot原生插件配置使用同一份config。保存时校验类型、范围与镜像地址，保留未修改和未知配置项；发现配置已被其他页面修改时拒绝覆盖，提示重新读取。保存失败会恢复内存配置。多数配置实时生效，配置说明中要求重载的项目仍需重载插件。
- **数据管理**：存储空间概览、SQLite数据库、JSON文件三个子标签。概览分类显示数据库、JSON、模型权重、独立环境及其他文件的数量、大小、占比和用途；扫描最多20000个文件，超限明确标注部分统计。SQLite按表展示真实字段，每页50行，长字段可展开。JSON按对象、数组逐层浏览，支持返回上一级和分页，每页50项，单文件在线预览限制20MiB。

## 数据和权限

运行日志、配置、数据管理面向已登录AstrBot管理面板的用户，与其他插件管理操作一样属于管理视图。数据管理展示插件原有磁盘记录，包括已被业务名单屏蔽群的留存数据；名单控制业务采集和分析，不代替管理面板的登录权限。数据库使用只读连接，只能查看预先列出的本插件表；JSON仅允许查看预先列出的业务文件，不接受任意文件路径，不修改或删除文件。

JSON查看的是磁盘快照，活跃候选池等尚未到定时写盘的内存变化可能暂未显示。今日关系图直接读取当前内存记录。现有今日老婆数据以群ID保存；好感度沿用平台、机器人、群三元范围独立计算。仅有今日老婆记录时仍可选择该群，好感度无可用范围时显示为不可查看，不伪造零分或互动次数。

控制台的群名和昵称优先用缓存，缺失时才补查，且每群每范围最多24小时一次；完整缓存不进行定时请求。OneBot补查时批量读取成员名片/昵称，包含发起者与被抽到的人；QQ官方的群资料接口有权限限制，成员名称仍依赖事件缓存。新收到的聊天发送者名称可直接更新显示，页面本身不下载头像或调用大模型。

新增`web_group_profiles`仅存群名、成员ID与昵称映射、补查时间和状态，不保存聊天正文。补查时间与结果都持久化，插件重启不重置24小时限制，失败也不会逐次刷新重试；页面会提示尚未获取的昵称或群名。此缓存与好感度原有七张表一起按60天规则清理。模型与运行环境作为程序缓存保留。

## 代码位置

后端统一放在`src/web/`：`dashboard.py`注册页面接口，`admin.py`处理日志、配置和存储，`analytics.py`计算好感度统计与历史，`marriage.py`读取今日关系，`profiles.py`处理名称缓存与24小时缺失补查。AstrBot要求的静态入口在`pages/affinity/`，页面脚本和样式随插件分发。图谱库只有根目录`vis-network.min.js`一份；网页通过鉴权的`affinity/network-script`接口读取该固定文件并在当前页面加载，兼容页面静态资源不能越过页面目录的限制，不接收客户端文件路径，不访问CDN。
